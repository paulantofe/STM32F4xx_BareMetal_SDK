Detailed Description

STM32F407xx Bare-Metal SPI driver demo.

This demo uses a shift register to display digits on a 7-segment one digit display. Each button press cycles through the digits from 0 to 9.

Note
The hardware used in this demo is a custom PCB designed by me. TO RUN THIS DEMO: Ensure that the default main.c is excluded from build and this file is included in the project's source path.

Hardware Setup:

  • Shift Register (SN74HC595N)
  • One Digit 7-segment Display (5611AH)
  • Push Button
  • 220R Resistor x 7 (for each used segment)
  • 0.1 µF Capacitor (for hybrid button debounce)
