Detailed Description

Header file for GPIO peripheral support.

This header file provides the configuration and handle structures for the GPIO peripherals on the MCU. It includes user macros for pin modes, output types, speeds and pull-up/pull-down resistors, along with the API function prototypes for GPIO initialization, read/write operations and interrupt handling.
