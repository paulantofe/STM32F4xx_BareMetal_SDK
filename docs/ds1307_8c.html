Detailed Description

Source file for the DS1307 Real-Time Clock BSP driver.

This source file contains the implementation of the APIs for communicating with the DS1307 RTC module over I2C. It includes functional code for device initialization, reading and writing time and date registers, as well as helper functions for BCD (Binary-Coded Decimal) conversions.
