Detailed Description

Board Support Package (BSP) driver header for the LCD1602 display.

This header file provides hardware pin mappings, application configuration macros and standard HD44780 instruction codes specific to the LCD1602 display. It also exposes the public API prototypes for initializing the module in 4-bit mode, controlling the cursor position, and transmitting commands or character string data via standard GPIO control.
