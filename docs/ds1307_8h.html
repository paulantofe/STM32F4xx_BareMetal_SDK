Detailed Description

Board Support Package (BSP) driver header for the DS1307 Real-Time Clock (RTC).

This header file provides register mappings, the I2C device address and configuration macros specific to the DS1307 RTC chip. It also exposes the public API prototypes for initializing the module, managing the square-wave (SQ) output, and reading or writing time and date data over the I2C bus.
